# Flip Blocks Plugin

A custom WordPress plugin for creating Gutenberg blocks.

## Features

- Includes static and dynamic blocks.
- Fully translatable with `.pot` files.
- Uses modern WordPress tooling.

## Installation

1. Copy the folder `flip-blocks` to `wp-content/plugins/`.
2. Activate the plugin in the WordPress admin panel.
3. Edit posts/pages using the Gutenberg editor to see the blocks.

## Development

- Run `npm start` for development mode.
- Run `npm run build` to build production files.
